# KPI dashboard (anonymised)

Static page showing team contribution points collected by the tick-tick Telegram bot.

**No personal data here.** People are shown as "Сотрудник 1…N". Real names, task titles and task
numbers never reach this repository: the builder inspects the finished payload and refuses to
write the page if it finds any of them.

- `index.html` — the page itself (data is embedded, no external scripts, fonts or trackers)
- `data.json` — the same aggregates as a separate file

Both files are generated by `dashboard/build.py` in the private bot repository and pushed here
once a day by `deploy/publish_dashboard.sh` running on the bot server.
